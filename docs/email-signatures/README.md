| File | Mailbox |
| --- | --- |
| `tochukwu.html` | t.nnamdi@swizel.co |
| `contact.html` | contact@swizel.co |

The images load from `https://www.swizel.co/email/signature/` (`public/email/signature/`
in this repo), so they show for every recipient once the site is deployed. Do not
move or rename those images — every email already sent points at them.

## Installing in Apple Mail

1. Open the file in **Safari**, press Cmd+A, then Cmd+C.
2. Mail › Settings › Signatures → select the account → select or add (+) a signature.
3. Click into the signature box, Cmd+A, Cmd+V.
4. Untick **Always match my default message font**.
5. Pick it in **Choose signature** for that account.

Outlook and Gmail work the same way: open the file in a browser, copy, paste into the
signature editor.
